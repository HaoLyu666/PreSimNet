# Top-2 重训练全量测试报告

## 实验设置

- 训练 checkpoint: `checkponint/ed64_inl20_ol20_drop0.1_tl1_nh4_od2_gama0.9_qv1_nt2_gru_new_2-top2/epoch21_e.tar`
- 测试数据: `../data/test_data.npy`
- 测试样本数: 2,246,939
- 路由方式: 对 `cf_probs` 取 Top-2 后重新归一化，再聚合两个专家的加速度。
- 结果目录: `fig/vis/routing_top2_trained_full_test`

## 主要结论

1. Top-2 重训练后，hard Top-1 误选样本数为 20,819，占 0.927%；Top-2 未覆盖真实交互类型的样本数为 392，占 0.017%。
2. 在 hard Top-1 误选样本中，Top-2 覆盖并“救回”20,427 个样本，占 hard routing 错误样本的 98.12%。
3. 在 hard Top-1 误选样本上，Top-2 的 RMSE 优于 hard Top-1，说明 Top-2 对交互类型边界附近或分类不确定样本有补偿作用。
4. 但与旧权重直接采用 Top-2 的结果相比，Top-2 重训练后的全量 RMSE 略差；因此这次重训练更适合作为补充实验或鲁棒性检查，不建议直接替换当前主结果。
5. Cross-family Top-2 的样本比例较高，但第二专家权重通常极小。所有 cross-family 样本中，第二专家原始 softmax 权重均值为 0.00662，中位数为 4.32e-08，说明所谓“混合”大多不是两个物理模型的大幅混合，而是近似由主专家支配。
